## 道徳的ジレンマ選択ゲーム

トロッコ問題・ハインツのジレンマ等15シナリオの2択を体験し、功利主義・義務論・徳倫理の3軸で倫理スタイルを診断するパーティゲーム。

### 機能
- 15のジレンマシナリオ（2択）を順番に出題
- 各選択肢に功利主義・義務論・徳倫理スコアを内部付与して集計
- 最終結果をSVGレーダーチャートで3軸可視化
- 倫理スタイル診断（功利主義タイプ/義務論タイプ/徳倫理タイプ/バランス型）
- 友人との比較用URLパラメータ付きリンク生成
- localStorage による過去5件の診断結果保存

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- SVG手描きレーダーチャート
- URLパラメータによる診断結果共有（Base64エンコード）
- localStorage 永続化
